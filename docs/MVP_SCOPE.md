# MVP Scope Boundaries — CreatorAI

## IN-SCOPE (Frozen Hackathon MVP)
- Project creation and dashboard view
- Video drag-and-drop upload (MP4/MOV, up to 100MB)
- Gemini multimodal video analysis (summary, viral moments, hooks, captions)
- Automated FFmpeg clip trimming from timestamps
- Creator Studio with synchronized video playback, scrubbing, and clip preview
- Clip reordering and text editing for hooks/captions
- FFmpeg final export stitching selected clips into 9:16 format
- Direct file download of export MP4

## OUT-OF-SCOPE (POST-MVP / Not for Hackathon)
- Professional multi-track video editing (transitions, speed ramping, color grading)
- Payment systems, Stripe, subscriptions
- Social OAuth authentication
- Direct social media publishing APIs (TikTok, YouTube Shorts, Instagram)
- Multi-user collaboration, comments, and WebSockets
- Custom AI model fine-tuning
- Microservices, Docker Swarm, Kubernetes
- Multiple databases (Postgres, Mongo, Redis)
